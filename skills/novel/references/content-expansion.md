# 内容扩充（不注水）

对应证据面：写章被字数门禁退稿（低于本书下限，见 `novel_briefing` 的「本章字数目标」）；`novel_noai_scan` 的 dilution 维走高。补字数时读这里。

核心原则：**每一处扩充必须同时服务于故事**。补字数不是「加段落」，是把已有因果写开。

## 先诊断，再动手

| 症状 | 特征 | 补法 |
|---|---|---|
| 场景太薄 | 读者看不清位置、行动条件、人物关注点 | 补影响行动与感受的场景细节（光线/温度/气味/空间关系，选**人物此刻会注意的**，一种感官够就不叠） |
| 跳跃太快 | 关键场景一笔带过 | 关键时刻放慢：尝试、受阻、调整、后果各给一拍 |
| 情感平面 | 读者感受不到角色情绪 | 内心世界展开——但用动作与克制呈现（他盯着那杯放凉的茶，没续），不直写「他很悲伤」 |
| 应对缺失 | 从问题直接跳到结果 | 把「选了什么、付了什么代价」写出来；必要时穿插相关次要情节 |
| 对话干瘪 | 对话只传信息 | 加层次：潜台词、权力博弈、沉默、打断（见 dialogue.md） |

## 五条防注水红线（命中任何一条即砍）

1. **无关风景堆砌**——与角色情绪/情节走向无因果的景色；
2. **凑字回忆**——不推进人物弧光的「他想起当年……」；
3. **复述已知**——换个说法把读者已知道的事再说一遍（重复句段机审会拦）；
4. **冗长过渡**——不必要的路程、等待、日常流水账；
5. **寒暄对话**——「嗯」「啊」「哦」与信息量皆无的对话注水。

**唯一判据：删掉这段扩充，故事是否变差？** 答案是否＝注水，删。

## 场景肌理充实（扩得最安全的一种）

场景不是「地点」，是综合体。三维度各取**服务于此刻**的一项：

- 感官层：人物此刻会注意、影响判断或感受的细节；
- 空间层：角色在空间里的位置、移动、与物件的距离；
- 情绪层：环境如何映射或反衬角色当前心理。

示范（悬疑场景，稀薄→充实）：

> 稀薄（约 60 字）：他走进案发现场。这是一间普通卧室，床上躺着一具女尸。窗户开着，窗帘在风中飘动。
>
> 充实（约 280 字）：门锁完好，没有撬痕。他推门时，一股混合着廉价空气清新剂与隐约腐败的气味涌出来，甜腻得反胃。他屏住呼吸侧身挤进门缝。卧室比想象中更小——十平米出头，一张一米五的床占了三分之一。床单是浅粉色的，洗了太多次，褪成灰白。女尸仰面躺着，双手交叠在腹部，像是被人刻意摆放过的；头发梳得极整齐，刘海丝毫不乱——这在死者身上不太寻常。窗户半开着，白色纱帘被穿堂风一下一下鼓起又落下，像某种缓慢的呼吸。窗外是六楼的水泥地：若是跳窗，凶手的手艺极好，或者根本没打算跳窗。床头柜上水杯里还剩小半杯水，水面没有灰尘——最近才倒的。

注意充实版的每一笔都在**给推理供料**（门锁/床单/头发/水杯→凶手与死者的关系线索），没有一笔是纯装饰。

## 与 dsh 机制的衔接

- 补字数后**整章重走门禁**（字数/重复/内容门禁照跑），不是只把差额拼上去；
- 批量路径已有「短稿有界续写」：初稿低于下限时自动补写一次（不许重复已有句子，超上限不裁剪按失败处理）；
- 扩完自查 dilution 维：把「注水段落」写进 `novel_noai_scan` 的白名单（novel_style whitelist）前先问判据——**它服务故事才留，不服务就删**，白名单是「这是我刻意写的」，不是「给我掩盖注水」。
