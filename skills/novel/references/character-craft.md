# 人物塑造

对应证据面：`novel_character` 卡（外在底色/动机/缺陷）与 voice 语言基因卡（句长/口头禅/禁忌）；`novel_audit voice` 的 missingVoiceCards（有台词无卡即点名）。人物扁平、说话一个味时读这里。

## 核心判据：矛盾创造深度

- 人物必须有**内在矛盾**（想要 X 但怕 Y / 信奉 A 却在做 B）——单一动机的人物读三章就见底；
- 矛盾要**外化成选择**：每章给一次「付代价的选择」，选择即人设（见「用选择揭示本质」）。

## 侧面揭示三法（替代贴标签）

1. **动作替代标签**：不写「他很谨慎」，写他进门先退后半步、视线先扫窗；
2. **选择揭示本质**：两个都要付代价的选项里他选哪个——比十段独白都准；
3. **习惯暴露真相**：反复做的小动作（每次撒谎前理袖口）是读者自己拼出人物的材料。

## 主角

- 主角必须有：**可执行的欲望 + 一个会被情节反复触碰的缺陷**（缺陷不能只在第一幕摆出来，之后躺平——那是人设不是弧线）；
- 缺陷致命化：关键节点让缺陷直接导致失败一次，读者才信它。

## 反派

- 好反派的标准：**自己的逻辑里他是对的**（动机自洽）；
- 动机分层：表面动机（钱/权）→ 真实动机（创伤/信念）→ 与主角的**镜像关系**（主角的未来失败形态常是反派现在的生活）；
- 反派停走（全书不推进、不升级）＝ 单面纸板，`novel_arc` 给反派也建维度线（威胁度/暴露度）。

## 配角

- 功能性配角必须至少承担一种：揭示主角面（镜像/衬托）、推进某条支线、兑现某个承诺/伏笔；
- 三个以上配角同台时查 voice 卡：每人一句「只有他会这么说的台词」，说不出＝人设混了。

## 与 dsh 台账的配合

- 人物卡字段照写：**外在底色 / 核心欲望 / 缺陷 / 动机**；多角色场先建 voice 卡再开写（句长基线、口头禅、禁用词）；
- 弧光维度（成长/信任度/嫌疑度…）随 `novel_arc update` 逐章落账，不靠「记得推进」；
- 多角色同台时，`novel_briefing` 的主角卡吃独立配额（buildContextPack 的 320 独立位），配角卡按出场注入——注入的是**卡片**不是回忆录，卡写满细节等于没写。
