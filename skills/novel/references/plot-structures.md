# 情节结构模板

对应证据面：全书深扫 `novel_project check fullscan`（关系线/弧线停走）；`novel_arc diagnose` 的 no-move（全书≥20章只推进过一次）。开卷前定结构、中期查「结构在不在走」时读这里。

## 三幕（全书级骨架，卷/篇章按此配平）

- **第一幕 设置（~25%）**：日常世界→扰动事件→第一转折点（主角无法退回日常）。
- **第二幕 对抗（~50%）**：升级的阻碍、中点反转（胜/败的假面揭穿）、至暗时刻。
- **第三幕 结局（~25%）**：总攻→代价结算→新常态（呼应第一幕的初始姿态）。

## 按题材取模板（只列骨架差异）

- **悬疑**：谜题出现→调查深入（误导线索成批入场）→真相揭示（真相必须早于揭示**埋了证据**——对应伏笔台账的 plan 回收）。
- **言情**：相遇（带冲突的相遇）→发展（关系升格与外部阻力交替）→考验→和解/错位。
- **惊悚/动作**：短章快切（5–6 章一个单元），每章末必留具体钩子；时间压力是主轴。
- **反转向**：反转点必须能向前回溯解释——反转前至少埋过两处「当时读起来合理」的草蛇灰线（伏笔 setup 必须带 plan 章号，反转章即回收章）。

## 章节级节奏（与 dsh 的配额纪律对齐）

- 每章有**冲突或转折**（章节级判据）：纯过渡章限 1–2 章连排，连续 3 章以上无冲突＝节奏塌陷，`novel_pacing` 的刹车档（brake）会拦；
- 每 600–900 字一次微兑现（信息/小反转/情绪落点）——SKILL.md 写作纪律已有，此处是它的技法展开；
- **弧线推进是硬账**：单人物维度（成长/信任度/嫌疑度…）≥15 章未推进 → major 质量债自动落账（`novel_arc update` 补推进）；全书 20 章只推进一次 → warning（no-move）。停走的弧线不靠「下一章记得写」，靠台账。

## 草蛇灰线（中文技法，伏笔台账的写法依据）

- 伏笔要**伪装成闲笔**：一次随口提及、一个背景物件、一个不经意的动作；
- 每处伏笔进台账时定好回收章（`foreshadow_setup` 的 plan）——「埋了」不等于「记住了」，没进台账的伏笔＝全书深扫里的无 plan 项；
- 回收要**改变前文的理解**（回声钩子），不是把信息再说一遍（那是复述，进 dilution）。
